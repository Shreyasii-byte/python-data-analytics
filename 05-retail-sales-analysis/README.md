
# Retail Sales Analysis 📊

## 📌 Project Overview

This project focuses on analyzing retail sales data using Python to understand business performance, identify sales trends, evaluate profitability, and generate meaningful business insights.

The analysis is performed using the Sample Superstore dataset.

## 🎯 Objectives

- Analyze overall sales and profit performance.
- Identify top-performing product categories and sub-categories.
- Examine monthly sales trends and patterns.
- Compare sales and profitability across regions.
- Identify valuable customers based on purchasing behavior.
- Understand the relationship between discounts and profit.
- Generate data-driven business insights.

## 💡 Business Insights

The analysis aims to identify:

- Which product categories generate the highest sales.
- Which sub-categories contribute most to profitability.
- Which regions perform best.
- How sales change over time.
- Which customers contribute the most revenue.
- Whether higher discounts are associated with lower profitability.

Actual findings and values are documented in the Jupyter Notebook after running the analysis.

## 🚀 How to Run

1. Download the `retail_sales_analysis.ipynb` notebook.
2. Open [Google Colab](https://colab.research.google.com/).
3. Upload the notebook.
4. Download the Sample Superstore dataset from [Kaggle](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final).
5. Upload the CSV when prompted in the notebook.
6. Run all cells to reproduce the analysis.

**Source:** Sample Superstore Dataset – Kaggle
