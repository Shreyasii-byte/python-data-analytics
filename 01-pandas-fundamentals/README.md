
# Pandas Fundamentals 🐼

## 📌 Overview

This folder contains practical exercises covering Python Pandas and NumPy for data analysis and manipulation.

The goal is to understand how to work with structured datasets, perform calculations, filter records, and extract useful insights.

## 🎯 Topics Covered

- Creating Pandas DataFrames and Series
- Loading and exploring datasets
- Understanding rows, columns, and data types
- Selecting and filtering data
- Sorting records
- Handling missing values
- Removing duplicate records
- Grouping and aggregating data
- Performing calculations using NumPy

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Google Colab
